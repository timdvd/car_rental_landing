# Car Rental One-Page Website
## A clean, modern, and fully responsive one-page website template for car rental services. Designed to showcase available vehicles, highlight rental features, and make booking simple and user-friendly.

### Features:
 - Responsive Design – Optimized for all screen sizes and devices.
 - Car Showcase – Display available vehicles with images, details, and pricing.
 - Smooth Navigation – Single-page scroll with anchored sections.
 - Modern UI – Clean layout with eye-catching visuals and icons.
   
### Technologies Used:
 - HTML5 – Semantic and structured markup.
 - CSS3 – Responsive styling with animations and transitions.
 - JavaScript (ES6+) – Adds interactivity and dynamic form handling.
